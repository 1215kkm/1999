# 디자인 적용 순서

1. 01_wardrobe_home_FINAL.png: 최종 홈 방향. 4열 옷 그리드, 종류/계절/위치 필터, 한 벌 선택, 보관 위치 화면.
2. 02_mobile_screens_REFERENCE.png: 등록·추천·비교·코디북 참고. 이 시안의 Today/오늘 홈과 구형 메뉴는 적용하지 않는다.
3. 03_web_admin_extension_REFERENCE.png: PC 옷장, 관리자, 확장 패널의 배치 참고.

이미지들은 시각적 목업이며 HTML/Figma 소스가 아니다. 레이아웃·컴포넌트로 재구현해야 한다. 이미지 속 글자/숫자/통계는 예시다. 특히 관리자 이미지의 파일 저장 용량 5GB 표기는 실제 Supabase Free 1GB와 다르므로 복제하지 않는다. 현재 요금은 구현 시 다시 검증한다.

모바일 옷 그리드 기본 4열, 3/5열 전환. 각 옷은 같은 시각적 크기의 배경 제거 사진. 이름/가격 등 반복 정보를 줄이고 선택/상세에서 노출한다. PC는 넓이에 따라 열 수를 늘리고 선택 시 우측 상세 패널을 고려한다. 필터는 보관 위치·계절·종류를 조합한다. 하단 CTA가 마지막 줄 옷을 가리지 않도록 안전 여백을 둔다.

빈 옷장, 필터 결과 없음, 업로드 중/실패, AI 대기/실패, 오프라인, 동기화 충돌, 세탁/대여 상태를 별도로 디자인한다. 실제 모델 사진 없이 시작해도 옷장/조합 흐름이 동작해야 한다.
