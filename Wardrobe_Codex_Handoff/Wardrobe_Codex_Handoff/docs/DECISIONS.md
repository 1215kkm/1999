# 확정 사항과 보류 사항

## 사용자 요구로 확정
- 소유한 옷과 액세서리로 추천. 메인에서 내 옷을 한눈에 확인.
- 위치/옷장을 미리 등록하고 옷 등록 시 간단히 선택. 계절·종류별 조회.
- 한 벌을 고정한 반수동 추천, 날씨·행사·스타일·색상 조건.
- 코디 저장, 착용일 및 기간별 횟수. 비포/애프터 비교.
- iOS·Android·웹·Chrome 확장이 같은 계정을 공유.
- 무료 운영 우선. Supabase Free 시작 후보. 이메일·모니터링 유료 구독은 필수 예산에서 제외.
- 인식·배경 제거는 로컬 AI 우선. 기본 추천은 규칙 기반부터.
- 유료 가상 착용 5,000장 예산은 삭제. 가상 착용은 선택 기능.
- 관리자 통계는 유입·전환·유지·AI 오류·동기화·용량까지 상세하게.
- GitHub 연동 희망, 설치형 Codex에서 개발 계속.

## 제안된 구현 방향 — 실제 환경 검증 필요
React TypeScript 웹, Expo 모바일, MV3 확장, Supabase, 무료 정적 호스팅, Python AI worker. 먼저 반응형 웹 핵심 흐름을 완성하고 동일 데이터 계약으로 플랫폼 확장. 기본 코디는 생성 이미지 없이 기존 옷 컷아웃을 조합한다.

## 후속 기능
가족 대여/공유, URL 이미지 가져오기, 공개 코디·팔로우·지역 커뮤니티, 제휴 구매·티어, 중고 가격 제안, 수선/리폼 제안, 세탁·소재 사전, 퍼스널 컬러/체형 참고, 메이크업, 총가격, 유사 코디, AI 친구·칭찬, 영상 워킹·실시간 반응, 얼굴 합성 장면 생성. 첫 버전에 한꺼번에 넣지 않는다. 캐릭터는 사용 권한을 확보한 자산만 사용한다.

## 중요한 구분
내 옷만 사용하더라도 사진 속 몸/포즈에 입히려면 별도 가상 착용 연산이 필요하다. 생성 재시도는 실패하거나 품질이 낮은 결과를 다시 만드는 것이다. 소유 옷 조합을 섞는 기본 추천과 구분한다.
무료 모델도 GPU 장비·전기·관리 비용은 있다. 인식/배경 제거 도구 라이선스와 가중치 라이선스는 별개다. Supabase 무료 파일 저장 1GB는 시안의 5GB 숫자보다 우선하며, 실제 구축 시 최신 공식 조건을 다시 확인한다.
앱스토어 검색 첫 페이지는 보장할 수 없다. 제목·설명·현지화·품질·평가 등으로 최적화하고 성과를 측정한다.

## 아직 미정
최종 앱 이름/도메인, 실제 GitHub 저장소 URL 및 공개 범위, Supabase 프로젝트와 로그인 제공자, GPU VRAM/OS 및 운영 시간, 출시 국가/언어, 개발자 계정 상태, 최종 과금 모델. 로컬 화면 개발은 이 결정 없이 진행 가능하다.
경쟁 앱 매출·홍보 및 공개 게시물 태그 조건은 검증된 제품 요구로 채택하지 않는다. 필요하면 별도 최신 조사한다.
