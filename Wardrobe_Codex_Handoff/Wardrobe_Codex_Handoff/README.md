# 내 옷 기반 AI 코디 앱 — 설치형 Codex 인계
작성일: 2026-10-16 / 가칭: 오늘의 옷장

## 시작
1. ZIP을 로컬 작업 폴더에 압축 해제한다.
2. 설치형 Codex에서 해당 폴더를 연다. 기존 GitHub 프로젝트가 있다면 그 저장소를 먼저 열고 이 자료를 docs/handoff 등에 복사한다. 기존 AGENTS.md는 덮어쓰지 않는다.
3. START_HERE.md의 프롬프트를 입력한다.
4. 실제 저장소 URL이 아직 정해지지 않았다면 로컬 구현부터 시작한다. 다른 프로젝트 저장소를 추측해 연결하지 않는다.

## 포함 자료
- START_HERE.md: 복사해서 입력할 첫 작업 지시
- AGENTS.md: 프로젝트 개발 원칙
- docs/PLAN.md: 코딩 에이전트가 읽기 쉬운 기획서 전체 텍스트
- docs/Wardrobe_App_Plan_v1_1.docx 및 PDF: 사람이 검토할 기획서
- docs/DECISIONS.md: 확정 사항, 후속 기능, 미결정 사항
- docs/IMPLEMENTATION.md: 구현 순서 및 완료 기준
- docs/DATA_AND_ANALYTICS.md: 데이터·권한·통계의 초기 명세
- docs/ENVIRONMENT.md: 환경 준비와 필요한 계정
- design/: 화면 시안 3장 및 적용 지침
- MANIFEST.json: 파일 목록과 SHA-256

## 현재 상태
기획서와 이미지 시안만 완성됐다. 실행 가능한 앱 소스, 실제 DB, 로그인 연동, GitHub 저장소, 배포 및 스토어 등록은 아직 만들지 않았다. 이미지 시안의 버튼과 수치는 실제 기능이나 운영 실적이 아니다. 이전 채팅이나 ChatGPT의 파일 링크에 접근할 필요 없이 이 폴더만 읽고 이어가도록 구성했다.
