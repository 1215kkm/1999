내 옷으로 AI 코디를 추천하는 앱 개발을 이어서 진행해줘.
먼저 이 폴더의 README.md, AGENTS.md, docs/DECISIONS.md, docs/PLAN.md, docs/IMPLEMENTATION.md, docs/DATA_AND_ANALYTICS.md, docs/ENVIRONMENT.md, design/README.md를 읽고 디자인 PNG 3장을 확인해줘. 기존 저장소라면 기존 코드와 적용되는 개발 지침부터 확인하고 보존해줘.

메인은 내 옷을 한눈에 보는 옷장 그리드야. design/01_wardrobe_home_FINAL.png를 가장 우선해줘. 모바일은 기본 4열, 3/5열 전환, 메뉴는 옷장·AI 코디·코디북·마이. 광고나 큰 추천 카드로 옷 목록을 가리지 마.

최종 목표는 iPhone·Android·웹·크롬 확장 동기화야. 권장 구조는 React/TypeScript 웹, Expo 모바일, Manifest V3 확장, Supabase 공통 백엔드, Python 로컬 AI 작업기야. 기존 프로젝트가 있다면 무조건 재생성하지 말고 적합한 구조로 통합해줘.

이번 첫 작업에서는 반응형 웹의 옷장·위치 필터·옷 등록·옷 상세·한 벌 고정 추천·코디 저장까지 동작하는 로컬 데모를 구현해줘. 사진 업로드는 로컬 미리보기와 기본 입력까지, AI 처리와 원격 동기화는 미연결 상태를 명확히 표시해줘. 옷장 사진은 사용자 제공 자료나 사용 허용된 자산만 사용하고 시안 전체를 앱 배경으로 붙이지 마. 처음에는 테스트 데이터와 브라우저 로컬 저장을 쓰고, 나중에 Supabase로 바꿀 수 있도록 데이터 접근 계층을 분리해줘. 파일/Blob 이미지는 IndexedDB 등 적절한 방식으로 관리해줘.

기본 추천은 실제 보유 중인 아이템 ID만 조합하고, 고정한 옷은 유지하며 세탁·대여 중 옷은 제외해줘. 무료 로컬 AI를 우선하고 유료 API 자동 호출은 넣지 마. 가상 착용은 기본 기능과 분리해서 나중에 모델 라이선스와 GPU 성능을 검증해줘.

GitHub에서 관리할 수 있게 구성하고 기존 remote를 확인해줘. 저장소가 없거나 계정 연결이 안 되어도 가능한 로컬 구현은 계속해줘. 비밀키는 저장소에 넣지 마. 연결 안 된 로그인·통계·동기화를 완료했다고 표현하지 마.
