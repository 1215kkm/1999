# area · 내 옷장

내 옷장을 관리하고 날씨·스타일·상황에 맞춰 AI 코디를 추천받는 모바일 웹앱 데모입니다.

- 바로 써보기: https://1215kkm.github.io/1999/
- 빌드 없이 `index.html`을 브라우저로 열어도 실행됩니다.

## 주요 기능
- 옷장: 위치·계절·상태·소유자 필터, 2/4/8열 보기, 다중 선택, 여러 각도 사진 스와이프
- 옷 등록: 촬영(9:16·16:9) → 배경 제거 → 색상·종류 자동 인식 → 상세 정보/고급 설정
- AI 코디: 날씨 반영, 고정할 옷, 스타일·무드, 미보유 아이템 추천
- 직접 조합, 코디북(자동조합 16개, 가족 옷 섞어 입기, 둘러보기·판매), 코디 히스토리(달력), 코디 묻기

## 참고
- 데이터는 각 사용자의 브라우저(localStorage, IndexedDB)에만 저장됩니다.
- 추천은 규칙 기반 엔진이며, 날씨는 Open-Meteo를 사용합니다.
- 로그인·결제·가족 공유는 데모 화면입니다.

## 구조
